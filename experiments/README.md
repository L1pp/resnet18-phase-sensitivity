- `legacy/phase_sensitivity/`: the original public ResNet18 phase-sensitivity scripts.
- `legacy/bezier/`: selected Bézier inverse-problem entry points.
- `phase_and_mechanism/`: selected Phase 1/2/3, mechanism-probe, and SGD anchor-rescue code.

- `tracks/track_b_core/`: core function-selection implementation, protocols, and tests.
