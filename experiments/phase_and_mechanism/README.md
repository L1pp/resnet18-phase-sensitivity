# Phase and mechanism code archive

This directory contains a selected public subset of the project's main geometry-localization research line.

- `phase1_gap_rep/`: frozen GAP representations, probes, subspace analyses, and Phase 1.7–1.8 entry points.
- `phase2_overnight/`: position coverage, architecture, content, symmetry, dense evaluation, and recovery experiments.
- `phase3_high_upside/`: controlled operators, equivariance/group-law checks, representation diagnostics, and Track A–F entry points.
- `mechanism_probe/`: spectral, optimizer, tangent-space, and MLP mechanism probes.
- `sgd_anchor_rescue/`: bounded anchor-rescue protocol, metrics, decisions, and tests.

Machine-specific checklists, transfer/packaging helpers, local closeout scripts, and several later operational packages are not part of this public subset. Their scientific outcomes remain described in `../../docs/EXPERIMENT_SUMMARY_CN.md`.

Historical imports and path defaults were not globally rewritten. Adapt them in a separate working copy if reuse is needed.
