# Selected results

This directory contains lightweight material chosen to make the research record readable without publishing the complete local artifact archive.

- `legacy_phase_sensitivity/` preserves the small result set already published in the original repository.
- `figures/` contains a small selection of Bézier, identifiability, and Track A figures.
- `tables/` contains compact summaries and reports, not complete prediction dumps or training returns.

The figures and tables should be interpreted together with `../docs/EXPERIMENT_SUMMARY_CN.md`. File inclusion here does not upgrade an exploratory or single-seed result into a general conclusion.
